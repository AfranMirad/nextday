# NextDay

Global habit / day-counter app (Flutter). Local-first. TR + EN.

## Run

```bash
flutter pub get
flutter run
```

## Brand

- Name: **NextDay**
- Package: `com.rizaaksu.nextday`
- Icon: `assets/brand/nextday_icon.png`

## Language

Device locale by default. Change anytime in Account → Language.

## Ads + Remove ads

Infrastructure is in the app (AdMob banner + IAP `nextday_remove_ads`).
Defaults use Google **test** ad IDs.

See [docs/MONETIZATION.md](docs/MONETIZATION.md) for the one-time AdMob / store product setup (only IDs to paste).
